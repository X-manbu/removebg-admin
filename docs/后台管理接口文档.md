# 智能抠图系统 - 后台管理接口文档

## 通用约定

- **Base URL**: `http://{HOST}:{PORT}`（生产环境请使用实际域名）
- **认证方式**: JWT Bearer Token，请求头格式 `Authorization: Bearer <token>`
- **权限要求**: 所有接口需要**管理员权限**，非管理员用户访问将返回 `code: 2003`

### 统一响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

### 错误码字典

| code | HTTP 状态码 | 含义 | 说明 |
|------|------------|------|------|
| 0 | 200 | 成功 | 正常处理 |
| 1001 | 400 | 参数错误 | 缺少参数、格式错误等 |
| 2001 | 401 | 未授权 | 未登录或登录已过期 |
| 2003 | 403 | 禁止访问 | 非管理员用户 |
| 5000 | 500 | 处理失败 | 服务内部错误 |

## 系统配置

### 1. 获取系统配置

获取当前系统所有配置项。

**请求**

```
GET /api/admin/config
Authorization: Bearer <token>
```

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "initial_points": 10,
    "matting_cost": 1,
    "redemption_code_default_days": 30,
    "redemption_code_default_points": 10
  }
}
```

**配置项说明**

| key | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| initial_points | number | 10 | 新用户初始点数 |
| matting_cost | number | 1 | 单次抠图消耗点数 |
| redemption_code_default_days | number | 30 | 兑换码默认有效期（天） |
| redemption_code_default_points | number | 10 | 兑换码默认赠送点数 |

---

### 2. 更新系统配置

批量更新系统配置。

**请求**

```
PUT /api/admin/config
Content-Type: application/json
Authorization: Bearer <token>
```

**请求体**

```json
{
  "initial_points": 20,
  "matting_cost": 1
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| key | string/number | 是 | 配置项的值，支持数字和字符串 |

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "message": "配置已更新"
  }
}
```

**前端调用示例**

```javascript
async function updateConfig(configs) {
  const res = await fetch('/api/admin/config', {
    method: 'PUT',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify(configs)
  });
  return await res.json();
}
```

## 兑换码管理

### 1. 批量生成兑换码

生成指定数量的兑换码。

**请求**

```
POST /api/admin/redemption-codes/generate
Content-Type: application/json
Authorization: Bearer <token>
```

**请求参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| count | number | 是 | - | 生成数量 |
| points | number | 是 | - | 每个兑换码赠送的点数 |
| batchNo | string | 否 | null | 批次号，便于管理 |
| expiresDays | number | 否 | 永不过期 | 有效期（天数） |
| maxUses | number | 否 | 1 | 最大使用次数 |

**请求示例**

```json
{
  "count": 100,
  "points": 10,
  "batchNo": "202602spring",
  "expiresDays": 30,
  "maxUses": 1
}
```

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "codes": [
      "AB23-CD45-EF67-GH89",
      "JKLM-NPQR-STUV-WXYZ",
      "..."
    ],
    "count": 100,
    "batchNo": "202602spring"
  }
}
```

**兑换码格式说明**

- 格式：`XXXX-XXXX-XXXX-XXXX`（16 位，4 组 4 位字符）
- 字符集：大写字母 A-Z（排除 I、O）+ 数字 2-9（排除 0、1）
- 示例：`AB23-CD45-EF67-GH89`

---

### 2. 查询兑换码

查询兑换码列表，支持筛选和分页。

**请求**

```
GET /api/admin/redemption-codes?batchNo=202602spring&status=active&limit=20&offset=0
Authorization: Bearer <token>
```

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| batchNo | string | 否 | 批次号筛选 |
| status | string | 否 | 状态筛选：active/disabled |
| code | string | 否 | 兑换码模糊搜索 |
| limit | number | 否 | 每页数量，默认 100 |
| offset | number | 否 | 偏移量，默认 0 |

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "codes": [
      {
        "id": 1,
        "code": "AB23-CD45-EF67-GH89",
        "batch_no": "202602spring",
        "points": 10,
        "expires_at": "2026-03-10T00:00:00.000Z",
        "max_uses": 1,
        "used_count": 0,
        "status": "active",
        "metadata": null,
        "created_at": "2026-02-08T10:00:00.000Z",
        "created_by": 1
      }
    ],
    "total": 100
  }
}
```

**字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| status | string | active: 有效, disabled: 失效 |
| used_count | number | 已使用次数 |
| expires_at | string/null | 过期时间，null 表示永不过期 |

## 用户管理

### 1. 调整用户点数

直接设置用户的点数余额（管理员操作）。

**请求**

```
POST /api/admin/users/:userId/points
Content-Type: application/json
Authorization: Bearer <token>
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| userId | number | 用户 ID |

**请求体**

```json
{
  "amount": 100,
  "reason": "活动赠送"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| amount | number | 是 | 设置的点数（非负整数） |
| reason | string | 否 | 操作原因，默认"管理员调整" |

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userId": 123,
    "points": 100,
    "message": "点数已调整"
  }
}
```

**前端调用示例**

```javascript
async function setUserPoints(userId, amount, reason) {
  const res = await fetch(`/api/admin/users/${userId}/points`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    },
    body: JSON.stringify({ amount, reason })
  });
  return await res.json();
}
```

### 前端请求封装示例

```typescript
// api.ts
const BASE_URL = '/api';

interface ApiResponse<T = any> {
  code: number;
  message: string;
  data: T;
}

async function request<T>(
  endpoint: string,
  options: RequestInit = {}
): Promise<ApiResponse<T>> {
  const token = localStorage.getItem('token');

  const res = await fetch(`${BASE_URL}${endpoint}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`,
      ...options.headers,
    },
  });

  const data = await res.json();

  // 处理 401 未授权
  if (res.status === 401 || data.code === 2001) {
    localStorage.removeItem('token');
    window.location.href = '/login';
    throw new Error('未授权');
  }

  // 处理 403 禁止访问
  if (res.status === 403 || data.code === 2003) {
    throw new Error('需要管理员权限');
  }

  return data;
}

// 系统配置
export const adminApi = {
  // 获取系统配置
  getConfig: () => request<any>('/admin/config'),

  // 更新系统配置
  updateConfig: (configs: Record<string, string | number>) =>
    request('/admin/config', {
      method: 'PUT',
      body: JSON.stringify(configs),
    }),

  // 生成兑换码
  generateCodes: (params: {
    count: number;
    points: number;
    batchNo?: string;
    expiresDays?: number;
    maxUses?: number;
  }) =>
    request('/admin/redemption-codes/generate', {
      method: 'POST',
      body: JSON.stringify(params),
    }),

  // 查询兑换码
  getRedemptionCodes: (params: {
    batchNo?: string;
    status?: string;
    code?: string;
    limit?: number;
    offset?: number;
  }) => {
    const query = new URLSearchParams(
      Object.entries(params)
        .filter(([_, v]) => v !== undefined)
        .map(([k, v]) => [k, String(v)])
    ).toString();
    return request(`/admin/redemption-codes?${query}`);
  },

  // 调整用户点数
  setUserPoints: (userId: number, amount: number, reason?: string) =>
    request(`/admin/users/${userId}/points`, {
      method: 'POST',
      body: JSON.stringify({ amount, reason }),
    }),

  // 点数变更日志
  getPointLogs: (params: {
    userId?: number;
    reason?: string;
    limit?: number;
    offset?: number;
  }) => {
    const query = new URLSearchParams(
      Object.entries(params)
        .filter(([_, v]) => v !== undefined)
        .map(([k, v]) => [k, String(v)])
    ).toString();
    return request(`/admin/logs/point-changes?${query}`);
  },

  // 兑换记录日志
  getRedemptionLogs: (params: {
    codeId?: number;
    userId?: number;
    limit?: number;
    offset?: number;
  }) => {
    const query = new URLSearchParams(
      Object.entries(params)
        .filter(([_, v]) => v !== undefined)
        .map(([k, v]) => [k, String(v)])
    ).toString();
    return request(`/admin/logs/redemptions?${query}`);
  },
};
```

### React 组件示例

```tsx
// 兑换码生成页面
import React, { useState } from 'react';
import { adminApi } from './api';

export default function GenerateCodes() {
  const [form, setForm] = useState({
    count: 100,
    points: 10,
    batchNo: '',
    expiresDays: 30,
    maxUses: 1,
  });
  const [result, setResult] = useState<string[] | null>(null);
  const [loading, setLoading] = useState(false);

  const handleGenerate = async () => {
    setLoading(true);
    try {
      const res = await adminApi.generateCodes(form);
      if (res.code === 0) {
        setResult(res.data.codes);
      }
    } finally {
      setLoading(false);
    }
  };

  const handleExport = () => {
    if (!result) return;
    const blob = new Blob([result.join('\n')], { type: 'text/plain' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = `redemption_codes_${form.batchNo || Date.now()}.txt`;
    a.click();
  };

  return (
    <div>
      <h1>生成兑换码</h1>
      <form onSubmit={(e) => { e.preventDefault(); handleGenerate(); }}>
        <input
          type="number"
          value={form.count}
          onChange={(e) => setForm({ ...form, count: +e.target.value })}
          placeholder="生成数量"
        />
        <input
          type="number"
          value={form.points}
          onChange={(e) => setForm({ ...form, points: +e.target.value })}
          placeholder="赠送点数"
        />
        <input
          type="text"
          value={form.batchNo}
          onChange={(e) => setForm({ ...form, batchNo: e.target.value })}
          placeholder="批次号"
        />
        <input
          type="number"
          value={form.expiresDays}
          onChange={(e) => setForm({ ...form, expiresDays: +e.target.value })}
          placeholder="有效期（天）"
        />
        <button type="submit" disabled={loading}>
          {loading ? '生成中...' : '生成'}
        </button>
      </form>

      {result && (
        <div>
          <h2>生成结果（{result.length} 条）</h2>
          <button onClick={handleExport}>导出</button>
          <textarea
            readOnly
            value={result.join('\n')}
            rows={10}
            style={{ width: '100%' }}
          />
        </div>
      )}
    </div>
  );
}
```
