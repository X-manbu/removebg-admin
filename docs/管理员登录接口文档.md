# 智能抠图系统 - 管理员登录接口文档

## 概述

后台管理系统通过 **用户名 + 密码** 登录，独立于微信小程序的登录方式。登录成功后返回 JWT Token，后续使用该 Token 访问所有管理接口。

## 通用约定

- **Base URL**: `http://{HOST}:{PORT}`
- **Content-Type**: `application/json`
- 所有响应均为 HTTP 200，通过 `code` 字段区分业务状态

### 错误码字典

| code | HTTP 状态码 | 含义 | 说明 |
|------|------------|------|------|
| 0 | 200 | 成功 | 登录成功 |
| 1001 | 400 | 参数错误 | 缺少用户名或密码 |
| 2002 | 401 | 登录失败 | 用户名或密码错误 |

> **安全说明**：无论是用户名不存在、密码错误还是用户非管理员角色，接口统一返回 `code: 2002, "用户名或密码错误"`，不暴露具体原因。

---

## 接口详情

### 管理员登录

**请求**

```
POST /api/admin/login
Content-Type: application/json
```

> 此接口**无需** Authorization 请求头。

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 管理员用户名 |
| password | string | 是 | 管理员密码（明文传输，生产环境务必使用 HTTPS） |

**请求示例**

```json
{
  "username": "admin",
  "password": "your_password"
}
```

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "username": "admin",
      "role": "admin"
    }
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.token | string | JWT Token，用于后续请求认证 |
| data.user.id | number | 用户 ID |
| data.user.username | string | 用户名 |
| data.user.role | string | 角色，固定为 `"admin"` |

**失败响应 — 参数缺失**

```json
{
  "code": 1001,
  "message": "缺少用户名或密码",
  "data": null
}
```

**失败响应 — 登录失败**

```json
{
  "code": 2002,
  "message": "用户名或密码错误",
  "data": null
}
```

---

## Token 使用

登录成功后，将返回的 `token` 存储到 `localStorage`，后续所有管理接口请求携带：

```
Authorization: Bearer <token>
```

Token 过期后接口返回 `code: 2001`，前端应跳转到登录页。

## 前端对接指南

### 1. 登录请求封装

```typescript
interface LoginParams {
  username: string;
  password: string;
}

interface LoginResult {
  token: string;
  user: {
    id: number;
    username: string;
    role: string;
  };
}

async function adminLogin(params: LoginParams): Promise<LoginResult> {
  const res = await fetch('/api/admin/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(params),
  });

  const data = await res.json();

  if (data.code !== 0) {
    throw new Error(data.message);
  }

  // 存储 token
  localStorage.setItem('token', data.data.token);
  localStorage.setItem('user', JSON.stringify(data.data.user));

  return data.data;
}
```

### 2. 请求拦截器集成

在已有的 `request` 封装中补充登录失败处理：

```typescript
async function request<T>(
  endpoint: string,
  options: RequestInit = {}
): Promise<ApiResponse<T>> {
  const token = localStorage.getItem('token');

  const res = await fetch(`/api${endpoint}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...options.headers,
    },
  });

  const data = await res.json();

  // Token 过期或未登录 → 跳转登录页
  if (data.code === 2001) {
    localStorage.removeItem('token');
    localStorage.removeItem('user');
    window.location.href = '/login';
    throw new Error('登录已过期');
  }

  // 非管理员
  if (data.code === 2003) {
    throw new Error('需要管理员权限');
  }

  return data;
}
```

### 3. 路由守卫示例（React Router）

```typescript
function RequireAuth({ children }: { children: React.ReactNode }) {
  const token = localStorage.getItem('token');

  if (!token) {
    return <Navigate to="/login" replace />;
  }

  return <>{children}</>;
}

// 路由配置
<Routes>
  <Route path="/login" element={<LoginPage />} />
  <Route
    path="/admin/*"
    element={
      <RequireAuth>
        <AdminLayout />
      </RequireAuth>
    }
  />
</Routes>
```

### 4. 登录页面示例（React）

```tsx
import React, { useState } from 'react';
import { useNavigate } from 'react-router-dom';

export default function LoginPage() {
  const navigate = useNavigate();
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState('');
  const [loading, setLoading] = useState(false);

  const handleLogin = async (e: React.FormEvent) => {
    e.preventDefault();
    setError('');
    setLoading(true);

    try {
      const res = await fetch('/api/admin/login', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ username, password }),
      });

      const data = await res.json();

      if (data.code !== 0) {
        setError(data.message);
        return;
      }

      localStorage.setItem('token', data.data.token);
      localStorage.setItem('user', JSON.stringify(data.data.user));
      navigate('/admin');
    } catch {
      setError('网络错误，请重试');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div style={{ maxWidth: 400, margin: '100px auto', padding: 24 }}>
      <h1>后台管理登录</h1>
      <form onSubmit={handleLogin}>
        <div style={{ marginBottom: 16 }}>
          <label>用户名</label>
          <input
            type="text"
            value={username}
            onChange={(e) => setUsername(e.target.value)}
            placeholder="请输入用户名"
            required
            style={{ width: '100%', padding: 8 }}
          />
        </div>
        <div style={{ marginBottom: 16 }}>
          <label>密码</label>
          <input
            type="password"
            value={password}
            onChange={(e) => setPassword(e.target.value)}
            placeholder="请输入密码"
            required
            style={{ width: '100%', padding: 8 }}
          />
        </div>
        {error && <div style={{ color: 'red', marginBottom: 16 }}>{error}</div>}
        <button type="submit" disabled={loading} style={{ width: '100%', padding: 8 }}>
          {loading ? '登录中...' : '登录'}
        </button>
      </form>
    </div>
  );
}
```

## 完整错误码参考

| code | HTTP 状态码 | 含义 | 触发场景 |
|------|------------|------|---------|
| 0 | 200 | 成功 | 登录成功 |
| 1001 | 400 | 参数错误 | 缺少 username 或 password |
| 2001 | 401 | 未授权 | Token 过期或无效（访问管理接口时） |
| 2002 | 401 | 登录失败 | 用户名/密码错误或非管理员 |
| 2003 | 403 | 禁止访问 | 非管理员角色（访问管理接口时） |

## 典型登录流程

```
┌──────────┐         ┌──────────┐         ┌──────────┐
│  前端     │         │  后端     │         │  数据库   │
└────┬─────┘         └────┬─────┘         └────┬─────┘
     │  POST /api/admin/login              │
     │  { username, password }             │
     │───────────────────────►│             │
     │                        │ SELECT by   │
     │                        │ username    │
     │                        │────────────►│
     │                        │    user     │
     │                        │◄────────────│
     │                        │             │
     │                        │ bcrypt.compare
     │                        │ check role=admin
     │                        │             │
     │  { token, user }       │             │
     │◄───────────────────────│             │
     │                        │             │
     │  存储 token 到 localStorage          │
     │                        │             │
     │  GET /api/admin/config               │
     │  Authorization: Bearer <token>       │
     │───────────────────────►│             │
     │  { code: 0, data: ... }│             │
     │◄───────────────────────│             │
```

## cURL 测试

```bash
# 登录
curl -X POST http://localhost:3000/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"your_password"}'

# 用返回的 token 访问管理接口
curl http://localhost:3000/api/admin/config \
  -H "Authorization: Bearer <token>"
```
